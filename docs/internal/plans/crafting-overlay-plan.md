# 合成助手策划入口

这是合成助手（Crafting Overlay）的内部策划入口。完整历史长文见 [工作台悬浮助手策划.md](../../工作台悬浮助手策划.md)。

## 当前状态

- `2.0.0.0` 正式版已包含 preview8、W2 / W3 和 InterceptBus。
- W6 / Phase 4c 的材料推荐与原料反查仍搁置，需重新评审产品形态。
- 玩家向说明已抽到 [用户文档：合成助手](../../user/crafting-overlay.md)。
- 外部接入说明已抽到 [API 文档：合成助手接入](../../api/crafting-overlay-integration.md)。

## 长文保留内容

旧策划保留以下信息：

- 社群玩家反馈原文与归类。
- JEI 对齐目标、Overlay 产品形态和取舍。
- Host、Placement、快捷键路由等设计决议。
- 分阶段交付、验收故事和后续搁置项。
- 下一 Agent 的内部接续入口。

## 维护规则

策划案只维护内部背景、决策、验收和待评审方向。稳定 API 不再以策划案为单一真相源；外部模组作者应阅读 `docs/api/`。
