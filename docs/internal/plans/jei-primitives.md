# JEI 对标与基元语句

这是合成助手对标 JEI 的内部设计入口。完整历史长文见 [合成助手-JEI对标与基元语句.md](../../合成助手-JEI对标与基元语句.md)。

## 用途

本资料用于解释合成助手为什么采用“同屏 Overlay + 配方预览 + `+` 摆放”的方向，以及哪些能力不能混入 REX 核心：

- 玩家打开合成容器时不应被切到全屏图鉴。
- 配方列表、配方详情和自动摆放是不同层级。
- `+` 摆放应由当前机器的 Target 解释。
- 流体、能量、管网等专有语义属于内容模组，不属于 REX 公共 API。
