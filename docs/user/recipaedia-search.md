# 图鉴搜索

RecipaediaEX 在图鉴页提供搜索框和筛选入口，用来从大量方块、自定义条目和配方关联中快速找到目标。

## 基本用法

1. 打开图鉴。
2. 在搜索框输入名称、拼音或筛选语句。
3. 点击搜索按钮，或使用支持自动搜索的版本直接等待列表刷新。
4. 点击条目查看详情或配方。

搜索结果仍然是图鉴条目，不是独立的配方列表。要看某个条目怎么制作或能做什么，请进入它的配方页。

## 常用搜索

| 需求 | 示例 |
|------|------|
| 按名称模糊搜索 | `铁 锭` |
| 精确名称 | `name=铁锭` |
| 查某个原料能做什么 | `@in:铜矿石` |
| 查某个产物怎么做 | `@out:铜锭` |
| 限定工作站 | `@crafter:熔炉` |
| 限定来源包 | `@pack:com.example.content` |
| 排除关键词 | `铜 -废` |
| 使用 OR | `(@in:煤 or @in:木炭) @crafter:熔炉` |
| 拼音搜索 | `tie` |

空格默认表示“同时满足”。前面带 `-` 表示排除；`=` 表示精确匹配；`:` 表示模糊匹配。

## 筛选按钮

搜索框旁的筛选按钮会打开高级筛选窗口。它适合不想手写查询语句的场景，例如选择条目类型、来源模组、工作站、配方类型、原料或产物。

确认筛选后，窗口会把条件写回搜索框并刷新列表。

## 分类和范围

全屏图鉴搜索默认在当前分类内过滤。如果当前分类是全量分类，效果接近全局搜索；如果切到某个子分类，则只在该分类中搜索。

合成助手里的搜索为了减少切分类成本，有搜索词时会走全库条目过滤。它和全屏图鉴的分类搜索语义不同。

## 搜索历史

版本支持搜索历史时，常用搜索词会保存在本地，下次进入图鉴或合成助手时可以快速复用。搜索历史属于玩家偏好，不随世界存档走。

## 常见问题

**搜不到某个内容怎么办？**  
先切到全量分类再试，或用 `@pack:` / `@mod:` 限定来源。如果是依赖模组的自定义条目，还需要该模组为条目提供图鉴和搜索元数据。

**`@in:` 和 `@out:` 有什么区别？**  
`@in:` 查“包含这个原料的配方会产出哪些条目”；`@out:` 查“哪些条目的产物匹配这个名称”。

**为什么同一个词在全屏图鉴和合成助手里结果不同？**  
全屏图鉴尊重当前分类；合成助手在输入搜索词时更偏向合成场景，会跨分类找全库条目。
