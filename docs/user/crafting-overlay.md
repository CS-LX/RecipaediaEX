# 合成助手

合成助手是在工作台、熔炉或内容模组机器界面内打开的悬浮配方浏览器。它的目标是让玩家在不离开当前合成界面的情况下查配方、看用途，并在支持的机器上用 `+` 自动摆放材料。

## 打开方式

- 打开已接入合成助手的工作台或机器界面。
- 按 Recipaedia 键，或点击界面上的助手入口。
- 如果当前界面不是合成类界面，Recipaedia 键会走全屏图鉴逻辑。

合成助手是当前合成界面的附属 UI。关闭工作台或机器界面时，助手也会跟随关闭。

## 可以做什么

| 功能 | 说明 |
|------|------|
| 同屏查配方 | 工作台或机器仍保持打开，右侧条带显示可搜索的图鉴条目 |
| 搜索条目 | 支持名称、拼音和常见 Token，详见 [图鉴搜索](recipaedia-search.md) |
| 查看配方 | 点击条目后显示配方预览，不需要切到全屏图鉴 |
| 切换工作站 | 同一条目有多种制作方式时，配方预览可按工作站分页 |
| `+` 自动摆放 | 支持的配方会出现 `+`，点击后从背包填入当前机器或合成格 |
| 长按连放 | 支持的版本中，长按 `+` 可连续摆放多组 |

## `+` 自动摆放规则

- `+` 只在当前机器支持该配方摆放时可用。
- 背包材料足够时，会按配方填入合成格或输入槽。
- 材料不足时，可能会部分填充，并提示缺少哪些材料。
- 对熔炉类输入区，`+` 只负责输入材料，不负责产物槽、残渣槽或燃料槽。
- 对化工、灌装等专有机器，是否支持物品槽或流体槽摆放由对应内容模组决定。

如果 `+` 灰显，通常表示当前配方没有可用摆放适配、当前机器不匹配、材料不足，或该配方只能预览不能自动填入。

## 会话记忆

合成助手会在本次游戏会话中记住部分状态，例如分类、列表滚动位置和搜索词。关闭并重新打开同一助手时，可能会恢复上一次状态。

这些状态不是世界进度，不写入世界存档。

## 已知限制

- “根据背包材料打开即推荐可合成物品”的体验仍属于后续优化方向。
- 并非所有依赖 RecipaediaEX 的机器都会自动支持 `+`；内容模组需要实现自己的 Host 和 Placement 适配。
- 全屏图鉴和合成助手的搜索范围不同：全屏图鉴偏当前分类，合成助手输入搜索词时偏全库。

## 给玩家的排查建议

如果助手没有出现，先确认当前界面是工作台、熔炉或内容模组机器，而不是箱子、设置页等非合成界面。如果某个机器始终没有助手入口，通常需要对应内容模组更新接入。
