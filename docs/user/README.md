# 用户文档

这里面向安装并游玩 RecipaediaEX 或依赖 RecipaediaEX 内容模组的玩家，只说明游戏里能看到、能操作的内容，不要求理解模组 API。

## 从哪里开始

| 想做的事 | 阅读 |
|----------|------|
| 在图鉴里快速找方块、配方、原料用途 | [图鉴搜索](recipaedia-search.md) |
| 打开工作台或机器时边看配方边合成 | [合成助手](crafting-overlay.md) |

## 功能边界

- RecipaediaEX 提供图鉴搜索、配方展示和合成助手框架。
- 具体机器是否支持合成助手、`+` 自动摆放、专有配方展示，由依赖 RecipaediaEX 的内容模组接入。
- 如果某个机器没有显示助手入口，通常表示该机器尚未接入 Overlay Host，或当前界面不是合成类界面。
