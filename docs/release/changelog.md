# 更新日志入口

RecipaediaEX 的版本变化和依赖模组适配指南继续维护在 [CHANGELOG.md](../CHANGELOG.md)。

## 阅读对象

- 依赖 RecipaediaEX 的其它模组作者。
- 准备发布 RecipaediaEX 新版本的维护者。
- 需要确认破坏性变更和迁移步骤的贡献者。

## 维护规则

- 新版本块放在旧文件顶部，最新版本在上。
- 破坏性变更必须在条目前明确标注。
- 外部模组需要改代码或改 `modinfo.json` 时，必须写“适配指南”。
- 策划案里的变更记录只保留设计历史，不替代 CHANGELOG。

## 旧入口

为避免链接断裂，实际日志暂不移动。请继续编辑 [../CHANGELOG.md](../CHANGELOG.md)。
